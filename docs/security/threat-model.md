# STRIDE Threat Model With DREAD Ratings

## Scope

This threat model covers repository-observable behavior in the NestJS API, data stores, provider integrations, background jobs, webhook flows, and deployment scripts. It does not validate production-only network controls, WAF/API gateway policies, AWS IAM role scopes, MongoDB/Redis TLS settings, or real secret values.

OWASP references use OWASP API Security Top 10 2023: <https://owasp.org/API-Security/editions/2023/en/0x11-t10/>.

## DREAD Scoring

Each threat is scored 0-10 for:

- Damage: impact if exploited.
- Reproducibility: consistency of exploitation.
- Exploitability: effort/skill/access needed.
- Affected users: blast radius.
- Discoverability: how easy it is to find.

Severity bands:

| Average | Severity |
|---:|---|
| 8.0-10.0 | Critical |
| 6.0-7.9 | High |
| 4.0-5.9 | Medium |
| 0.0-3.9 | Low |

## Highest Priority Fix Sequence

1. Fix device-token verification and add auth regression tests.
2. Add provider signature validation and replay protection for every public webhook.
3. Remove or lock down client-accessible order status mutation and notification endpoints.
4. Enforce object ownership for every order, wallet, and transaction-hash read/write.
5. Stop logging secrets and remove plaintext secret files where possible.
6. Turn on global whitelist/forbid validation and add body/array/string size limits.
7. Add provider timeouts, quotas, and circuit breakers for expensive flows.
