Threat Implementation Audit
Audit date: 2026-07-20
Scope: current worktree src/, docs/security/threat-model.md, package scripts,
Husky hook, and repository-observable deployment/scripts state. dist/ was
ignored. Deleted files in the current worktree are treated as absent from the
current source state.

No code or configuration changes are included in this file. This is a
plain-text interpretation of which threats from
docs/security/threat-model.md appear implemented, partially implemented, open,
or stale against the current source.

Implemented: T03, T04, T08, T15, T17

T06 - Mostly implemented
Fusion+ and native Fusion secret state now use encrypted Redis envelopes and
write with FUSION_SECRET_STATE_TTL_SECONDS, defaulting to 7200 seconds. Legacy
plaintext state is re-encrypted on read. Remaining risk is operational: Redis
ACL/TLS and encryption key handling depend on environment configuration, and
state cleanup on all exceptional paths is not fully proven beyond TTL expiry.
Evidence:
- src/api/v1/swap/1inch/1inch.service.ts
- src/api/v1/swap/1inch/1inch.fusion.native.swap.service.ts

T22 - Mostly implemented

requires http/https parsing, rejects URL credentials, requires HTTPS outside
dev, blocks localhost/private/internal hosts outside dev, and enforces exact

operational: those allowlist values should be governed separately from mutable
